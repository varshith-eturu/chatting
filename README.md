💬 Real-Time Chat App

A full-stack real-time chat application that allows users to authenticate, send messages instantly, and maintain seamless conversations across sessions.

🌐 Live Demo:
👉 https://chatting-s0qw.onrender.com/

🚀 Features

🔐 User Authentication (Login / Signup / Logout)

💬 Real-time messaging

📦 Persistent chat history

🟢 Online / Offline status handling

🧭 Clean and responsive UI

🛠 Tech Stack
Frontend

React

Zustand (State Management)

Axios

Tailwind CSS

Backend

Node.js

Express.js

MongoDB

Socket.io (for real-time communication)

🔐 Authentication Flow

User signs up or logs in

JWT token is generated

Token is stored securely

Protected routes validate token

On logout → token cleared and state reset

JWT Authentication
